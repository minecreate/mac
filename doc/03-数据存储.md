# LineNexus 数据存储约定

> 状态：已落地（边端 SQLite / 云 MySQL / 云 TDengine）  
> 更新：2026-10-09  
> 对应：`01-总体架构设计.md`、`02-开发进展.md`

---

## 1. 原则

| 侧 | 项目 | 存储 | 说明 |
| --- | --- | --- | --- |
| 边端网关 | `linenexus-edge`（Go） | **SQLite** | 现场单机、零运维、可离线；设备 / 点表 / 本地缓存落本地文件库 |
| 云平台 | `linenexus-cloud`（Java） | **MySQL** | 多租户业务元数据、网关注册、告警规则/事件等关系型数据 |
| 时序 | 云侧 `linenexus-monitor` | **TDengine** | 遥测、历史曲线、高频采样；不与业务表混在同一 MySQL 业务库 |

云边分离：边端持有现场权威配置与断网缓存；云侧持有租户视角的注册与编排元数据。设备点表当前以边端为准，云通过 `managementUrl` 代理访问。

---

## 2. linenexus-edge — SQLite

| 项 | 值 |
| --- | --- |
| 引擎 | SQLite（纯 Go：`glebarez/sqlite` + `modernc.org/sqlite`，`CGO_ENABLED=0`） |
| ORM | GORM |
| 默认路径 | `./data/edge.db`（`configs/config.yaml` → `sqlite.path`） |
| 主要数据 | 网关自身身份、南向设备、点表、遥测 outbox、本地消息等 |

配置片段：

```yaml
sqlite:
  path: "./data/edge.db"
```

代码入口：`linenexus-edge/internal/storage/db.go`。

---

## 3. linenexus-cloud — MySQL

| 项 | 值 |
| --- | --- |
| 引擎 | MySQL 8.x |
| 访问 | Spring Data JPA |
| 本地开发 | `root` / `root`，库名 `linenexus_asset` |
| JDBC | `jdbc:mysql://127.0.0.1:3306/linenexus_asset?...` |
| 建库脚本 | `linenexus-asset/src/main/resources/schema.sql` |
| 配置 | `linenexus-asset/src/main/resources/application.yml` |

### 3.1 当前库表（asset）

库：`linenexus_asset`

| 表 | 用途 |
| --- | --- |
| `edge_gateway` | 边端网关注册（id、name、tenant_id、status、last_seen_at、management_url、时间戳） |

设备 / 点表 / 读写仍走边端 SQLite，经 asset 的 `EdgeDeviceProxy` 转发，**不在 MySQL 重复存一份**（后续若做云侧镜像或影子设备，再单独立项）。

本地初始化：

```bash
mysql -uroot -proot < linenexus-cloud/linenexus-asset/src/main/resources/schema.sql
```

## 4. 时序库：TDengine（已定）

与 MySQL 分工：

| 数据类型 | 落点 |
| --- | --- |
| 租户、网关、策略、告警规则、任务定义、活动告警 | MySQL `linenexus_asset` |
| 测点历史、分钟/秒级采样、趋势查询 | TDengine 库 `linenexus`，超级表 `telemetry` |
| 边端断网缓冲 / 未上报队列 | 继续 SQLite（outbox），补传冲刷后续再做 |

本地依赖（TDengine + Mosquitto）：

```bash
cd linenexus-cloud && docker compose up -d
```

| 项 | 值 |
| --- | --- |
| 镜像 | `tdengine/tdengine:3.3.2.0` |
| 原生端口 | `6030` |
| REST / JDBC | `6041`（`jdbc:TAOS-RS://127.0.0.1:6041`） |
| 库 / 超级表 | `linenexus` / `telemetry` |
| 标签 | `tenant_id`, `gateway_id`, `device_id`, `point_id` |
| 列 | `ts`, `v_double`, `v_str`, `quality` |
| 默认保留 | 30 天（`linenexus.tdengine.keep-days`） |
| MQTT | 本机或 compose 内 Mosquitto `:1883`；主题 `linenexus/{gatewayId}/telemetry` |

服务：`linenexus-monitor`（`:18082`）订阅 MQTT → 写入 TDengine；历史/告警 API 经网关 `/api/monitor/**`。

## 5. 数据归属一览（当前）

```text
边端 MQTT TelemetryBatch
    │  linenexus/{gw}/telemetry
    ▼
Mosquitto :1883
    ▼
linenexus-monitor :18082
    ├─ TDengine linenexus.telemetry   ← 测点历史
    └─ MySQL linenexus_asset          ← alarm_rule / alarm_event；只读 edge_gateway

控制台 (Vue)
    │  /api/assets/...  /api/monitor/...
    ▼
Spring Cloud Gateway :18080
    ├─ linenexus-asset :18081
    │     ├─ MySQL edge_gateway / hmi / iam
    │     └─ HTTP 代理 managementUrl → edge
    └─ linenexus-monitor :18082
```
