## 2. 已实现（linenexus-edge）

技术约束：Gin + GORM + SQLite，`CGO_ENABLED=0`（`glebarez/sqlite` + `modernc.org/sqlite`），监听 `:8080`（现场亦有 `:8081` 部署），库文件 `./data/edge.db`。

### 2.1 运行与调试页

- 进程：`linenexus-edge/bin/edge.exe -config configs/config.yaml`
- 调试页：`http://localhost:8080/`（或部署端口）
- 左侧菜单：
  - **设备**：南向设备列表、点状态、读写、浏览
  - **上层通信**：北向 MQTT 配置、收发测试、gRPC 控制面配置
- 点击设备后展示该设备点表：当前值、读写属性、状态、行内写、本设备收发记录

### 2.2 南向适配器

| 协议 | 状态 | 实验室对象 | 点地址示例 |
|---|---|---|---|
| OPC UA | 已接通 | CODESYS `opc.tcp://192.168.3.37:4840`，用户 `mplc`，Basic256Sha256 + SignAndEncrypt | `{"nodeId":"ns=4;s=\\|var\\|CODESYS Control Win V3 x64.Application.PLC_PRG.i0"}` |
| Modbus TCP | 已接通 | Mac `192.168.3.28:5020` | `{"func":3,"offset":0,"type":"int16"}` |
| MQTT | 已接通 | 本机 Broker `tcp://127.0.0.1:1883` | `{"topic":"lab/line1/status"}` |

OPC UA 要点：

- 客户端证书在 `data/opcua/client_cert.pem`，CODESYS 必须先信任，否则握手只看到 `EOF`
- `GetEndpoints` 只取服务器证书和策略，**不改用户填写的 URL**
- 私钥必须是 PKCS#1 `RSA PRIVATE KEY`（gopcua v0.8.0）
- 浏览从 Objects 向下走；运行时只采点表，不扫全地址空间

Modbus / MQTT 南向细节同历史联调记录，此处不重复。

### 2.3 北向（上层通信）

| 通道 | 用途 | 现状 |
|---|---|---|
| MQTT | 遥测、命令、回执 | 可真连 Broker；telemetry / command / ack |
| gRPC | 点表下发、写点、回执 | 可配地址；云侧现以 HTTP 代理读写为主 |

### 2.4 存储模型（边端）

设备、点、收发消息、心跳、离线判定；删设备级联点和消息。

## 6. 已拍板的方向

1. 云边分离：边 SQLite / 云 MySQL + TDengine。  
2. 南向先 Modbus / OPC UA / MQTT。  
3. **工位只绑设备，Profile 挂执行设备。**  
4. 云不直连现场设备。  
5. 浅意 MES 不做 BOM/APS/仓储。
