# LineNexus 双产品拆分

> 更新：2026-10-09

| 产品 | 路径 | 定位 |
| --- | --- | --- |
| **云平台** | `D:\Mac\Project\LineNexus` | 多租户接入、点表、组态 HMI、系统管理 |
| **MES / 执行** | `D:\Mac\Project\LineNexus-MES` | 厂侧：工位、配方、订单、Run、锁、设备态 |

## 本仓（云平台）范围

- 服务：`gateway` `:18080`、`asset` `:18081`
- 前端：`:5173`
- 边端：`:8081`（可选，实验室联调）
- **已移除** `linenexus-execution` 与 `/exec/*` 菜单

## 与 MES 的关系

- 部署可不在同一机房；开发可分仓推进。
- 实验室本机可双开：端口与 Nacos `group` 已错开（见 MES 仓说明）。
- 联调时 MES 通过 HTTP 读写点（本仓 `asset` 或 MES 仓自带 `mes-asset`）。

## 启动（云）

1. Nacos 3.x `:8848`（勿用 1.4）
2. MySQL：`linenexus_asset`
3. `linenexus-asset` / `linenexus-gateway` / `linenexus-web`
4. 可选：`linenexus-edge` `:8081`
